# 分享说明 · 微信为何失败

## 根本原因

| 环境 | 能否网页一键发图到微信 |
|------|------------------------|
| 普通浏览器 / Chrome | ❌ 不能直接指定「发给微信」，只能打开**系统分享面板**，由用户点微信 |
| 微信内置浏览器 | ❌ **禁止**网页 JS 直接把本地图片发到聊天/朋友圈 |
| 微信公众号 JSSDK | ⚠️ 仅能分享**链接卡片**，需认证公众号 + 安全域名，**不能**塞本地 PNG |
| 原生 App + 系统分享 | ✅ 用户在系统面板里选微信（需 FileProvider/缓存文件） |

所以「分享至微信失败」通常是：

1. 在 **微信里打开网页** 点分享 → 接口不可用  
2. **桌面浏览器** 没有 Web Share → 只能下载  
3. 旧逻辑只分享了**文字**没有图，或分享被取消  

## 本 App 策略

点击「分享」打开面板：

| 按钮 | 行为 |
|------|------|
| 系统分享 | `navigator.share({ files })` 或 Capacitor Share + 缓存文件 |
| 保存图片 | 下载 PNG |
| 复制经文 | 剪贴板 |
| 微信 / 朋友圈 / 小红书 / IG / X / FB / WhatsApp | **保存图 + 复制文案 + 操作指引**；能调系统面板时优先调起 |

## 用户最佳路径（微信）

### 手机 Chrome / 系统浏览器 / App

1. 尺寸选 **方形 1080×1080**（朋友圈更合适）  
2. 点 **分享 → 系统分享 → 微信**  
3. 若没有微信：点 **微信** 按钮 → 图已保存 → 微信里从相册选  

### 已在微信内打开网页

1. **长按**预览图保存，或点「保存图片」  
2. 右上角 **… → 在浏览器打开** 再用系统分享（可选）  
3. 或：微信聊天 → + → 相册 → 选图  

## 开发注意

- 安卓 Capacitor 需 `@capacitor/filesystem` + `@capacitor/share`  
- 同步后：`npx cap sync android`

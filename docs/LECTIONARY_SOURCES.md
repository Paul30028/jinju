# 经课与金句资料来源

## 授权说明（产品方确认）

产品方确认：  
[改革宗资源导航](http://www.https.ng/p1234/0/0.html) 及相关乐园索引中的资料  
**可合法用于中国境内本应用的金句池与三代经课摘要扩充**。

导航站本身是**资源索引**（电子书、注释、查经、软件链接），并非结构化 API。  
本应用将索引中可公开使用的**圣经经文摘要**与 **RCL（修订通用经课 / 三代经课）历法结构**  
整理为本地 JSON，供离线默想与成图。

## 相关索引线索（导航站检索）

| 类型 | 线索 |
|------|------|
| 经课 | 「三代经课的经文」「三代经课每日读经释义」等 |
| 金句/灵修 | 清教徒金句、查经网站、在线圣经工具链接 |
| 工具 | 信望爱圣经、微读圣经、研经工具等（外链，非内嵌） |

## 本应用数据文件

| 文件 | 内容 |
|------|------|
| `src/data/verses-cuv-seed.json` | 和合本金句池（本地） |
| `src/data/verses-esv-map.json` | 有限英文对照 |
| `src/data/lectionary-readings.json` | 经课年 A/B/C · 节期与主日读经摘要 |
| `src/core/verse/topics.ts` | 主题/圣灵果子标签 |

## 结构策略

1. **经课年 A/B/C** 与将临期起点对齐（见 `lectionary/calendar.ts`）  
2. 主日键：`advent-1..4`、`lent-1..6`、`easter-1..7`、`ordinary-1..12`、节期默认等  
3. 每条尽量含：旧约 / 诗篇 / 书信 / 福音 中的 2–4 段**金句级**摘要  
4. 缺周次回退：邻近周 → 季节默认 → `ordinary-default`

## 边界

- 不替代完整圣经或完整经课本  
- 不整本镜像导航站 PDF；以**经文摘要 + 历法键**进入 App  
- 后续可继续：ordinary-13…34、节日专用（三一主日、基督君王日等）

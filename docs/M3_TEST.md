# M3 测试清单（收藏 · 制作 · 增强背景）

## 启动

```powershell
cd C:\Users\holyx\jinju-ri
npm run dev
```

打开 http://localhost:5173 ，建议 **Ctrl+F5**。

## 导航

应看到 5 个入口：**今日 · 制作 · 收藏 · 历史 · 设置**

## 验收

### 今日
1. 金句图背景更有层次（光斑 / 薄雾 / 暗角）
2. 点 **收藏** → 状态变为「已收藏」
3. 进入 **收藏** 页可见该条

### 制作 `/create`
1. 输入出处 + 正文 → **生成图片**
2. 可改主题/版式/尺寸、保存、分享、收藏
3. **填入今日金句** 可快速试用

### 收藏 `/collection`
1. 列表显示缩略图与经文
2. **取消收藏** 生效

### 历史 `/history`
1. 可 **回看生成**（重新出图）
2. 可 **删除** 单条 / **清空**

### 设置 `/settings`
1. 保存默认主题/版式/尺寸
2. 底部显示当前主题的 **AI 背景 Prompt 预览**（只读，供后期接 API）

# 金句日 · 免费版说明

## 包含

| 能力 | 说明 |
|------|------|
| 本地自动成图 | Canvas，不用 AI |
| 每日版式轮换 | 6 种免费版式 + 5 主题 |
| 中英双语 | 中文和合本 + 英文 ESV 本地对照 |
| 分享 | 系统分享 / 下载 + 文案 |
| 水印 | 「金句日」 |
| 主题 / 九果 / 经课 | 本地 |

## 6 种免费版式

1. 居中  
2. 居中引号  
3. 上方排版  
4. 下方卡片  
5. 右侧栏  
6. 左侧轨  

## 尺寸

- 1080×1920 故事/状态  
- 1080×1080 朋友圈/小红书  
- 1920×1080 横图  

## 暂不包含（付费预留）

- 去水印  
- L07–L12 高级版式  
- 高级主题包  
- 云同步  

## 测试

```powershell
cd $HOME\jinju-ri
npm run dev
```

打开 http://localhost:5173  
检查：自动出图、中英、换语言/版式/尺寸、保存、分享、右下角水印。

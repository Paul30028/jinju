## 功能验收

### 今日页 `/`

1. 打开后自动显示**今日经文**（出处 + 和合本正文）
2. 下方自动生成金句图片预览
3. 切换 **主题**（黎明 / 静夜 / 旷野）→ 图重新生成
4. 切换 **版式**（居中 / 上下 / 左右 / 竖排）→ 图重新生成
5. 切换 **尺寸**（竖版 / 方形 / 横版）→ 图比例变化
6. 点 **保存图片** → 下载 PNG
7. 点 **分享** → 系统分享或回退下载
8. 同一天多次刷新 → **经文不变**（日期种子稳定）

### 历史 `/history`

1. 在今日生成后进入历史 → 应出现今天的条目与缩略图
2. 点刷新可重新读取 localStorage

### 设置 `/settings`

1. 修改默认主题/版式/尺寸 → 保存
2. 刷新页面 → 今日页沿用默认偏好
